# 16. Keyboard shortcuts

[← Protocols](15-protocols.md) · [Contents](README.md) · [Troubleshooting →](17-troubleshooting.md) · 🇫🇷 [Français](../16-raccourcis.md)

On macOS, `Ctrl` stands for `⌘ Cmd`. The list is also shown in **Preferences → Keyboard shortcuts**.

## 16.1 Everywhere

| Key | Action |
|---|---|
| `Ctrl+K` | Command palette |
| `Ctrl+,` | Preferences |
| `Ctrl+N` | New session (Sites tab) |
| `Ctrl+Tab`, `Ctrl+PgDn` | Next tab |
| `Ctrl+Shift+Tab`, `Ctrl+PgUp` | Previous tab |
| `Alt+1` … `Alt+9` | Go to tab n |
| `Ctrl+W` | Close the tab (session, editor, diff) |
| `Ctrl+Shift+P` | Preview panel |
| `Ctrl+Shift+Q` | Open or close the bottom panel |
| `Esc` | Close the dialog, the menu or the palette |
| `Enter` | Confirm the dialog |

## 16.2 File panels

| Key | Action |
|---|---|
| `Tab` | Go to the other panel |
| `↑` `↓` `PgUp` `PgDn` `Home` `End` | Move the cursor |
| `Enter` | Open |
| `Backspace`, `Alt+↑` | Parent folder |
| `Alt+←`, `Alt+→` | Back, forward |
| Letters | Type-ahead search |
| `Space` | Select or unselect the item |
| `Insert` | Select or unselect, then move to the next one |
| `Shift+↑`, `Shift+↓`, `Shift+click` | Extend the selection |
| `Ctrl+click` | Add to or remove from the selection |
| `Ctrl+A`, `Ctrl+Shift+A` | Select all, unselect all |
| `Num +`, `Num −`, `Num *` | Select by mask, unselect by mask, invert the selection |
| `Esc` | Unselect, then clear the filter |
| `F2`, `Shift+F6` | Rename |
| `F3` | View |
| `F4`, `Shift+F4` | Edit, edit with an external editor |
| `F5` | Copy to the other panel |
| `Shift+F5` | Copy with the options |
| `F6` | Move to the other panel |
| `F7`, `Shift+F7` | New folder, new file |
| `F8`, `Delete` | Delete (to the trash when possible) |
| `Shift+Delete` | Delete for good |
| `F9` | Properties |
| `F10` | Close the tab |
| `Shift+F10`, Menu key | Context menu |
| `F12` | Transfer queue |
| `Ctrl+C`, `Ctrl+X`, `Ctrl+V` | Copy, cut, paste files |
| `Ctrl+Shift+C` | Copy the path |
| `Ctrl+R`, `Ctrl+F5` | Refresh |
| `Ctrl+F` | Filter |
| `Ctrl+L` | Type a path |
| `Ctrl+O` | Open a folder |
| `Ctrl+D` | Add to or remove from the bookmarks |
| `Ctrl+Alt+H` | Show hidden files |
| `Ctrl+S` | Synchronize |
| `Ctrl+=` | Compare folders |
| `Ctrl+B` | Synchronized browsing |
| `Ctrl+U` | Keep the remote folder up to date |
| `Ctrl+Shift+F` | Find files |
| `Ctrl+T` | Open a terminal |
| `Ctrl+Shift+X` | Run a command |

During a drag and drop: `Ctrl` (or `Alt`) forces a copy, `Shift` forces a move.

## 16.3 Editor and diff

| Key | Action |
|---|---|
| `Ctrl+S` | Save |
| `Ctrl+F` | Find and replace |
| `F3`, `Ctrl+G` / `Shift+F3`, `Ctrl+Shift+G` | Next / previous match |
| `Ctrl+Shift+L` | Select all the matches |
| `Ctrl+D` | Add the next match to the selection |
| `Ctrl+Alt+G` | Go to line |
| `Ctrl+Z`, `Ctrl+Y`, `Ctrl+Shift+Z` | Undo, redo |
| `Tab`, `Shift+Tab` | Indent, unindent |
| `Ctrl+/` | Comment or uncomment |
| `Alt+↑`, `Alt+↓` | Move the line |
| `Shift+Alt+↑`, `Shift+Alt+↓` | Duplicate the line |
| `Ctrl+Shift+K` | Delete the line |
| `Ctrl+Shift+[`, `Ctrl+Shift+]` | Fold, unfold |
| `Ctrl+Space` | Autocompletion |
| `Alt` + drag | Rectangular selection |
| `Esc` | Close the search panel |

### In a project

| Key | Action |
|---|---|
| `Ctrl+Shift+E` | Open the folder of the active panel as a project |
| `Ctrl+P` | Go to file |
| `Ctrl+Shift+F` | Search the project |
| `Ctrl+Alt+S` | Save all |
| `` Ctrl+` `` | Show or hide the terminal |
| `Ctrl+W` | Close the file shown |

## 16.4 Terminal

| Key | Action |
|---|---|
| `Ctrl+C` | Copy the selection; without a selection, interrupt the program |
| `Ctrl+V` | Paste |
| `Ctrl+Shift+C` | Copy the selection |
| `Ctrl+Shift+V` | Paste |
| Right-click | Copy the selection, or paste when there is none |
| `Ctrl+Shift+F` | Search in the terminal |

`Ctrl+C` and `Ctrl+V` always go to the program with the **Ctrl+Shift+C / Ctrl+Shift+V only** setting, and the right-click opens a menu with **Right-click → Menu** ([§ 12.6](12-preferences.md#126-terminal)). The other keys are sent to the shell.

## 16.5 Site list and palette

| Key | Action |
|---|---|
| `↑`, `↓` | Previous, next site or command |
| `Enter` | Connect (to all the selected sites), run the command |
| `Delete` | Delete the selected site, or the selected sites |
| `Ctrl+click`, `Shift+click` | Add a site to or remove it from the selection, select a range |
| `Shift+↑`, `Shift+↓` | Extend the selection |
| `Ctrl+A` | Select all the sites shown |
| `Esc` | Clear the selection |
| `Ctrl+S` | Save the site being edited |
